## 作業のすすめ方（この順番を守る）

1. 作業用ファイル `words_251-350.js` を作り、**10語ずつ**書き足していく
   （前回の `words_151-250.js` が見本になります。キーの順序・インデントをそろえる）
2. 10語書くごとに、必ず次の3回のチェックを通す
   1. **機械チェック**: `node validate.js --add words_251-350.js`
      → `ALL PASS` になるまで直す。警告（合否に関係しない項目）も可能な限り消す
   2. **読み直し**: 自分で語源・例文・和訳を読み返す
   3. **第三者チェック**: 別のエージェント（またはあなた自身の別チャット）に、
      仕様書とその10〜20語だけを渡して次を点検させる
      - 語源の説明が言語学的に正しいか（でたらめな分解になっていないか）
      - relatedWords が本当にその語根を共有しているか。同じ語根の綴り・訳語がファイル内で割れていないか
      - 例文の英語が自然・文法的に正しいか、和訳が正確で自然な日本語か
      - `meaning` の先頭語義・`meanings[0]`・`partOfSpeech` と例文の用法がそろっているか
      → 指摘は必ず反映してから次の10語へ進む
3. 100語そろったら `index.html` に差し込む（下の「差し込み手順」）
4. 音声を作る（下の「音声の作り方」）
5. `sw.js` の `VERSION` を1つ上げる（いまは `v10` → `v11`）
6. ブラウザで動作確認 → Commit → Push

## 音声の作り方（Piper）

音声ツールは `/Users/arutokamiya/Documents/Roots単語アプリ/音声ツール` にあります（`venv/bin/python` が使える）。
前回使ったスクリプトの作りは次のとおり。同じものを作って実行すれば、足りない分だけ作られます。

- 読ませる英文 = `RAW_WORDS` の `word` / `example` / `example2` / `relatedWords[].word`（前後の空白を除く）
- ファイル名 = その英文の **FNV-1a 32bit ハッシュ**（`charCodeAt` で計算）を8桁の16進数にしたもの。
  `index.html` の `clipHash()` と同じ計算にすること
- 声のモデル: 米 `en_US-lessac-high` / 英 `en_GB-cori-high`（`音声ツール/models/` にある）
- **`espeak_data_dir` には「espeak-ng-data フォルダを含む親フォルダ」を渡す**（例: `/tmp/roots-espeak`。
  そこへ `piper` パッケージ内の `espeak-ng-data` をコピーしておく）。直接 espeak-ng-data を渡すと動きません
- 速さ: 単語（3語以下）は `length_scale=1.18`、文は `1.05`
- wav で作って `afconvert -f m4af -d aac@22050 -b 64000 -c 1 入力.wav 出力.m4a` で m4a にする
- 保存先は `audio/us/<ハッシュ>.m4a` と `audio/uk/<ハッシュ>.m4a`
- 最後に `audio/us` `audio/uk` のファイル名一覧から
  `<script type="application/json" id="roots-audio-index">{"us":[…],"uk":[…]}</script>` を作り直して差し替える
- 100語ぶんで新しい音声は 550〜600 文 × 2（米英）＝ 1100〜1200 本くらい。20〜30分かかります
