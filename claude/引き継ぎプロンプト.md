## このアプリの番号の決まり（毎回これに従う）

- `part` は「id ÷ 10 の切り上げ」

### 1-1. 語源でやりがちな誤り（前回サブエージェントに20件指摘された）

**下の形は「似ているだけ」で語根を共有していません。関連語に非 synonym で置かない。**

| ✕ まちがい | ○ 正しい |
|---|---|
| improve は prove（試す）の仲間 | 別系統（古仏 *prou*「利益」）。approve の仲間ではない |
| grant と guarantee は同じ語族 | 別系統。grant は credere（信じる）系 |
| notion は nota（しるし）から | noscere（知る）から。notify なら nota でOK |
| tax は estimate（aestimare）の仲間 | 別系統（tangere「触れる」系） |
| harm は noc（傷つける）の仲間 | harm はゲルマン語系。synonym:true にする |
| stun は stup（ぼうっとする）の仲間 | 別系統（ex+tonare「雷鳴」）。synonym:true にする |
| banner は ban（公に言い渡す）＋ er | 別語（bandum「しるし・旗」）。banish なら ban でOK |
| allergy の all は「すっかり」 | ギリシャ語 allos「別の」 |
| parasol の para は「そばで」 | イタリア語 parare「防ぐ」 |
| double は dub ＋ le（もの） | dub ＋ pli（折る）。「二重に折る」 |
| species の es は複数の接尾辞 | ラテン語第5変化の単数形。分解しない |
| -ish は「〜にする」（selfish の場合） | 形容詞の -ish は「〜のような」。動詞の banish なら「〜にする」 |
| afford / arise / aware の a は ad | いずれも古英語の接頭辞。**ad と書かない** |
| beware の be は「すっかり」 | 「Be ware!（見張っていろ）」が固まった形 |
| modest は modus ＋ t（名詞） | -estus は名詞接尾辞ではない。分解しない |

**接頭辞の同化にも注意。** occur は `oc`（正しい同化形）、obtain は `ob`（同化しない）。

**語源不詳の語は断定しない。** stubborn は OED で語源不詳。
`etymologyConclusion` には書いてよいが、**`hook` に「語源ははっきりしないが〜と結びつけると覚えやすい」と添える**。

### 1-2. 反意語を `synonym:true` に入れない ← 前回の指摘

アプリは、関連語が全部 `synonym:true` だと見出しを**「意味の近い語」**にします。
そこに `honest`（cheat の反対）や `dry`（humid の反対）を入れると、
**「honest は cheat に意味が近い」と読めてしまいます。**
反意語ではなく、意味の近い語か、同じ語根の語を入れてください。

### 1-3. 「警告0件」にするコツ

`validate.js` の警告のほとんどは **「語根の語義が既存データとずれている」** です。
新しい語義を思いつく前に、**既存データで同じ綴りがどう訳されているか**を調べて、そちらに合わせる。

```bash
node -e 'const fs=require("fs"),vm=require("vm");
const s=fs.readFileSync("index.html","utf8");
const a=s.indexOf("const RAW_WORDS=["),b=s.indexOf("\n];",a);
const W=vm.runInNewContext(s.slice(a+"const RAW_WORDS=".length,b+2));
const r={};const add=t=>{if(!t)return;for(const m of t.split("→")[0].matchAll(/([A-Za-z-]{1,14})（([^）]+)）/g))(r[m[1]]=r[m[1]]||new Set()).add(m[2]);};
W.forEach(w=>{add(w.etymologyConclusion);(w.relatedWords||[]).forEach(x=>{if(!x.synonym)add(x.breakdown)})});
console.log(Object.keys(r).sort().map(k=>k+"("+[...r[k]].join("/")+")").join(" "));'
```

例：`re` に「離して」は無い → `後ろへ` を使う。`fic` は「する」ではなく `作る`。

### 1-4. 10語ごとに必ず見る追加項目

- **見出し語の重複**: 追加する語が既存の本編にすでに無いか
- **`meaning` の重複**: 先頭語義が既存の語と丸かぶりしていないか
  （今回 arise「持ち上がる」/ occur「起こる」、last「続く」/ persist「やり続ける」のように**ずらした**）
- **例文の語数**: 1文 8〜14語。7語だと不合格です
- **空所補充の検出**: `hugged` `dragged` `buried` のように子音を重ねる形・y→ied の形、
  不規則変化（`shook` `arose` `forgave`）はアプリが見つけられません。
  **1文目**を原形か `s / es / d / ed / ing` にすること（2文目が使われると警告が出る）
- **和訳の自然さ**: 和訳の中の見出し語にあたる日本語が、`meaning` の先頭語義と**そろっていて、かつ日本語として自然**か。
  （前回「1回戦で排除された」→「レジ袋を排除すべきだ」に例文ごと差し替えた）
- **`partOfSpeech`**: 許可された9種類だけ（接続詞は whereas のように節をつなぐ語だけ）（`自動詞・他動詞` は不可。`他動詞・自動詞` が正）。
  **`meanings[0]` と1文目の用法に合わせる。** 1文目が自動詞なら `自動詞` を選ぶ
- **`hook`**: 語根チップが2つ以上ある語に付けると警告。**分解できない語（チップ1つ）だけ**
- **語根の綴り**: `pos`（`posit` 不可）/ `grat`（`gree` `grac` 不可）/ `ad`（`a` 不可）

## 手順2. `index.html` に差し込む

N = 今回追加した語数。値は `node check-all.js` の「次に N 語を足すときの値」を見ること。

1. **Part α の id を N だけ後ろへずらす**
   （`{id:351,word:"hand in"` のように `{id:数字,word:"見出し語"` を1件ずつ置換。**α の中身は変えない**）
2. **新しい語は、α の直前に入れる** ← 前回ここで構文エラーを出した
   配列の**いちばん末尾**に足すと、その前にある α の最後の要素にカンマが無くて `SyntaxError` になります。
   `{id:<αの先頭番号>,word:` の行を探し、**その行の直前**に挿入すること
3. `const ALPHA_FROM=…;` を「元の値 ＋ N」に直す
4. `const WORDS_LAYOUT=…;` を1つ上げる。上のコメントに、その版で何をしたかを1行足す
5. **学習記録の引き継ぎ**（ここを忘れると生徒の○×が消えます）
   - `const v<前の版>IdToNew=id=>id>=<元のALPHA_FROM>?id+N:id;` を足す
   - **ひとつ前の読み替え関数を、この新しい関数に通す**
     （例: `const v8IdToNew=id=>id>=551?id+100:id;` → `const v8IdToNew=id=>v9IdToNew(id>=551?id+100:id);`）
   - `roots.listRecall.v<前の版>` を1つ上げ、前の版から読み替えて移す処理を足す
   - **`Cloud.pull` の中の `for(let v=2;v<=9;v++) lsDel(...)` の上限を新しい版に上げる**
6. `node validate.js` が **全語 ALL PASS** になることを確認

### 3-3. 語源コラム（`ROOT_NOTES`）の書き方

**このコラムのいちばんの価値は「知っているカタカナ語が、実は同じ語根だった」という驚きです。**

**お手本:**

```js
"clim":{
  title:"クライマックスと気候は同じ「傾き」",
  body:"【なぜ】ギリシャ語 klima は「傾き」。地球の傾きで土地ごとに日ざしが変わり、天気の性格が決まると考えられました。klimax（はしご）＝クライマックスも同じ家族です。\n【身近な日本語】クライメート（気候）、クライマックス（段を上りきった頂点）。\n【覚え方】斜めに差す日ざしの絵で clim。climate はその土地の長い目で見た天気。"
},
```

| | ○ こう書く | ✕ こう書かない |
|---|---|---|
| title | **カタカナ語を入口にした一文** | 「「傾き」clim」のような**定型**。これを書いたら不合格 |
| 【なぜ】 | もとの言語と語、そこから**意味がどう枝分かれしたか** | 語源をひとこと書いて終わり |
| 【身近な日本語】 | **実在するカタカナ語を3〜5個、かっこで意味つき**。ゲーム用語・商品名・スポーツ用語でもよい | 「日本語には入っていない」と書いて逃げる |
| 【覚え方】 | カタカナ語を手がかりに、**英単語2〜3語**の理屈をつなげる | 語根の意味をくり返すだけ |

- 本文は3段合わせて **100〜200字**
- **どうしてもカタカナ語が無いときだけ**【身近な英語】に切り替えてよい（前回は57件中5件だけ）。
  ただし「無い」と決める前に、ゲーム・スポーツ・IT・商品名・地名・食べ物まで探すこと。
  前回見つけた例:
  cheat →「ゲームのチート」、limin →「サブリミナル効果」、atmo →「ドルビーアトモス」、
  drown →「マイクラのドラウンド」、eag →「ビネガー（酸っぱい＝鋭い酒）」、
  stub →「チケットのスタブ」、bold →「文字のボールド」、guilt →「ギルティ」、
  soil →「園芸のソイル」、clim →「クライマックス」、gain →「オーディオのゲイン」、
  brave →「ブラボー」、self →「セルフレジ・セルフィー」
- 書いたあと、次で機械的に点検する:

```bash
node -e 'const fs=require("fs");const s=fs.readFileSync("index.html","utf8");
const i=s.indexOf("const ROOT_NOTES={"),j=s.indexOf("\n};",i),b=s.slice(i,j);
const re=/"([^"]+)":\{\s*title:"((?:[^"\\]|\\.)*)",\s*body:"((?:[^"\\]|\\.)*)"\s*\}/g;
const m=[];let x;while((x=re.exec(b)))m.push({k:x[1],t:x[2],y:x[3]});
const f=m.filter(e=>/^「[^」]+」[A-Za-z-]+$/.test(e.t));

```
定型タイトル・逃げの記述・3段欠けが **すべて 0件** になるまで直す。

### 5-2. 作るスクリプト（そのまま使える）

```python
import json, subprocess, sys, tempfile, wave
from pathlib import Path
TOOL = Path("/Users/arutokamiya/Documents/Roots単語アプリ/音声ツール")
REPO = Path("/Users/arutokamiya/Documents/GitHub/Roots")
ESPEAK = "/private/tmp/roots-espeak/espeak-ng-data"
VOICES = {"us": "en_US-lessac-high", "uk": "en_GB-cori-high"}
todo = json.load(open(sys.argv[1], encoding="utf-8"))
from piper import PiperVoice, SynthesisConfig
tmp = Path(tempfile.mkdtemp())
for acc, model in VOICES.items():
    voice = PiperVoice.load(str(TOOL / "models" / (model + ".onnx")), espeak_data_dir=ESPEAK)
    outdir = REPO / "audio" / acc
    made = 0
    for item in todo:
        t, h = item["t"], item["h"]
        dst = outdir / (h + ".m4a")
        if dst.exists():
            continue
        ls = 1.18 if len(t.split()) <= 3 else 1.05   # 単語はゆっくり、文は自然な速さ
        wav = tmp / (h + ".wav")
        with wave.open(str(wav), "wb") as f:
            voice.synthesize_wav(t, f, SynthesisConfig(length_scale=ls))
        subprocess.run(["afconvert", "-f", "m4af", "-d", "aac@22050", "-b", "64000", "-c", "1",
                        str(wav), str(dst)], check=True, capture_output=True)
        wav.unlink(); made += 1
        if made % 50 == 0: print(f"{acc}: {made} 作成", flush=True)
    print(f"{acc}: 合計 {made} 本", flush=True)
print("完了", flush=True)
```
