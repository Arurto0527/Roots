# Roots 内容ブラッシュアップの基準（2026-10-01）

今のデータは「正しい」。でも高校生が読んで **「わかる！」「へぇ！」「もう忘れない」** と思えるところまでは届いていない。
この文書は、全単語の説明文を 60点 → 100点 に磨くときの共通ルール。単語を新しく足すときもこの基準で書く。

---

## 1. 生徒が「わかる！」と思える5つの条件

| # | 条件 | 60点の書き方 | 100点の書き方 |
|---|---|---|---|
| ① | **知っている言葉から入る** | 語源だけを説明する | カタカナ語・中学英語・日本語の言い回しとつなぐ（オファー、サバイバル、インプレッション） |
| ② | **場面が目に浮かぶ** | 意味を別の抽象語で言い換える（「感じ取るはたらきに関わる」） | 人・物・動きが見える場面にする。「」のセリフも使ってよい |
| ③ | **「だから」が一本道でつながる** | 語根の意味と単語の意味が並んでいるだけ | 語根の意味 → 場面 → 単語の意味 が、間を飛ばさずにつながる |
| ④ | **仲間が一気に増える** | 難しい関連語を並べる | 「あ、あれも同じだ！」と思える身近な語で語根を体感させる |
| ⑤ | **やさしい日本語** | 「手だて」「事柄」「～のさま」「帯びる」など硬い言葉 | 中高生がふだん話す言葉。1文を短く |

**やってはいけないこと:** 語源や由来を作り話にすること。カタカナ語の使われ方があいまいなときは書かない。「～とされる」「はっきりしない部分もある」と正直に書くのはよい。

## 2. 項目ごとの書き方

### 2-1. イメージ文（`etymologyConclusion` の `→` より右）— いちばん大事

答え合わせ画面でいちばん大きく出る1行。**ここで「なるほど」が起きるかどうかで勝負が決まる。**

- `→` より左（語根チップ）と、`＝` より右（意味）は**変えない**。変えるのは「場面」の部分だけ
- 場面は「だれが・何を・どうする」が見えるように。抽象語の言い換えで終わらせない
- 「」のセリフを入れると一気に分かりやすくなることが多い
- `→` の右全体で **50字以内**（目安 20〜42字）

| 語 | 60点 | 100点 |
|---|---|---|
| advise | 自分に見えている景色を相手のほうへ差し出す＝忠告する | 「その先は危ないよ」と、自分に見えていることを相手に伝える＝忠告する |
| excuse | 責めのもとを自分の外に出して身を軽くする＝言い訳 | 「わざとじゃない」と、責めを自分の外へ押し出す＝言い訳 |
| agree | 相手の言うことが心地よく感じられてそちらへ寄っていく＝賛成する | 「それ、いいね」と心地よく感じて、相手の側へ寄っていく＝賛成する |
| sensory | 見る・聞くなど感じ取るはたらきに関わる＝感覚の | 目・耳・鼻・舌・肌で感じ取ることにかかわる＝感覚の |

すでに場面が見えている文（oppose「相手の正面に立ちはだかるように自分を置く」など）は**無理に変えない**。

### 2-2. ヒント（`etymologyProcess` の `→` より右）

出題面で押すヒント。日→英の向きでは**ここだけ**が手がかりになる。

- `→` より左は変えない。右は **30字以内、「…？」で終える**。見出し語そのものは書かない
- 新しいイメージ文の「途中まで」にそろえる（答えの一歩手前で止める）

### 2-3. つなぐ一言（`hook`）— 知っている言葉への橋

語源の説明の下に出る1〜2文。**「あ、知ってる！」「へぇ！」を起こす**ための欄。
（旧ルールでは「語源で分解できない語だけ」だったが、この改訂で**強いつながりがある語には付けてよい**に変える）

書いてよいのは次の5種類だけ。**どれにも当てはまらない語には付けない**（全体の半分くらいが目安。無理に作らない）。

| 種類 | 例 |
|---|---|
| a. カタカナ語 | offer：仕事の「オファー」が来る＝仕事を差し出される。 |
| b. 和製英語のわな | claim：日本語の「クレーム（苦情）」は英語では complaint。claim は「当然だと主張する」。 |
| c. 身近な英語の親せき | time：tide（潮）と同じ語から。Time and tide wait for no man.（歳月人を待たず） |
| d. 語法の型・まちがえやすさ | blame A for B（B のことで A を責める）の形で覚える。 |
| e. 分解できない語の覚え方 | 語源がない語の、場面や音での覚え方 |

- **60字以内**
- 語根コラム（`ROOT_NOTES`）に書いてある語根のカタカナ語をそのまま写すのではなく、**その単語ならでは**のつながりを書く
- `why`・イメージ文・関連語の breakdown・`usage` と同じことを書かない（`node check-all.js` が why との重なりを見つける）
- 和製英語（日本語と英語で意味がずれるカタカナ語）は、ずれていることをはっきり書く

### 2-4. なぜこの意味？（`why`）

語根の意味から単語の意味まで**飛躍がある語だけ**に書く（仕様書 §4-3 の ②型）。

- 形は `【なぜ】…\n【つながり】…` の2行。**120〜200字**
- 【なぜ】は「もとは○○ → こういう場面で使われるうちに → 今の意味」の順で。年号や言語名を並べすぎない（ラテン語・フランス語くらいまで）
- 【つながり】は、同じ流れで意味が変わった身近な語、カタカナ語、使い分けの注意
- すでにある why は、読みやすく直す（1文を短く・硬い言葉をやさしく）。内容の事実は変えない
- 語根だけで意味まで届く語（①型）には付けない

### 2-5. 意味の広がり（`etymologyMore`）

- `→` の右は `meanings` の文言そのまま（変えない）。左を **25字以内**で、1つ目の意味の場面から一歩だけ進めた場面にする
- `→` のない行（由来の一言）は、やさしい言葉に直してよい

### 2-6. 関連語の説明（`relatedWords[].breakdown`）

- 語（`word`）・意味（`meaning`）・`→` より左は変えない（英語を変えると音声が合わなくなる）
- `→` より右を、見出し語と同じ語根が**同じ働きをしている**ことが見える場面にする。全体で **45字以内**
- `synonym:true` の語は、**見出し語との使い分け**をやさしく1文で（「A は～、B は～」）

### 2-7. 変えないもの

英単語・英文（見出し語・例文・関連語・usage の英語部分）、`meaning` と `meanings`、発音、品詞、語根チップ（`→` より左）、id と並び順、Part α の中身。
→ 英語を変えると音声が端末の読み上げに切り替わってしまう。語根を変えるとピクトグラムと語根コラムがずれる。

語根そのものがまちがっていると思ったときは、**直さずに報告**する（`flags` に書く）。

## 3. 文体のきまり

- です・ます調にしない（イメージ文・ヒント・breakdown・hook）。why と語根コラムは「です・ます」でよい（今の書き方に合わせる）
- 硬い言葉 → やさしい言葉: 手だて→方法／事柄→こと／～のさま→～のようす／帯びる→もつ／存する→ある／なす→する／～せしめる→～させる
- 「～に関わる」「～するはたらき」で終わる言い換えは、具体的な物や動きに置きかえる
- 絵文字は使わない。「！」は多用しない（1語に1つまで）
- 英語の語は半角、日本語の句読点は「、。」

---

## 4. 作業の流れ（全語見直しのとき）

1. 50語ずつに分けて書き直す（書き手）。変えた項目だけを JSON で出す
2. 機械チェック（長さ・→の数・左側が変わっていないか・英語が変わっていないか）
3. 第三者チェック（`word-reviewer`）: 語源とカタカナ語の事実、why と hook の重なり、読みやすさ
4. index.html に反映 → `node validate.js` と `node check-all.js` を両方通す
