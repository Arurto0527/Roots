# タイトル: Roots #47 ③推理 ambidextrous（11/28 投稿1）｜Rootsで英単語｜語源で一発暗記
# 語根: ambi+dextr
# メモ: ambidextrous はアプリにない語なのでパーツを指定（ambi(両方|接頭|絵なし)+dextr(右の|語根)+ous(～な)＝両手利きの）。アプリの ambi は gloss が「まわりを」（ambition・ambiguous 用の絵）なので、意味が合わない今回は |絵なし にした。root 場面も {root ambi=両方 接頭 絵なし}
# メモ: dexterity・ambivalent もアプリにない語なのでパーツを指定して「番号なし」。dexter はアプリのパーツにないので意味は台本で指定（dexter=右の）。ambivalent の val はアプリの「力がある」（value・valid と同じ。Etymonline の valere「強い」とも合う）に合わせ、絵はアプリのまま
# メモ: 語源の根拠: Etymonline ambidextrous（1640年代「両手を同じように使える」、中世ラテン語 ambidexter から。14世紀末には「二枚舌の人」の意味もあった）・Etymonline ambi-（"both, on both sides"、もとはラテン語 ambi-「まわりに」）・Etymonline dexterity（1520年代「手先の器用さ」、ラテン語 dexteritas ← dexter「器用な」「右（手）の」）。Merriam-Webster ambidextrous（Late Latin ambidexter ＝ ambi- (both) ＋ dexter (right-hand side, skillful) ＋ -ous。意味 using both hands with equal ease）。Etymonline ambivalent（1916年の心理学用語、ambi-「両方」＋ラテン語 valentia「強さ」← valere「強い」。相反する気持ちを同時にもつこと）
# メモ: 雑学: Etymonline sinister（ラテン語 sinister「左の」は dexter「右の」の反対。占いで左に見えるしるし〈鳥など〉が不吉とされ「不吉な・悪い」の意味に。ギリシャの影響とされ、ローマ本来の占いでは左が吉だったという話もあるので、ナレーションは「今は不吉な」だけにして理由は言わない）
# メモ: 注意: 「右手が器用→器用」は Etymonline の dexter "skillful" と "right (hand)" の2つの意味をつないだ言い方。ambi はアプリでは「まわりを」だが、Etymonline・Merriam-Webster とも ambidextrous の ambi は "both" なので画面は「両方」
