# 型: ①カタカナ語 vis / vid（2026-11-17・Roots #26）
# 語根: vis
# メモ: television・video はアプリの見出し語にないので kata でパーツを指定。tele はアプリのデータにないので絵なし（Etymonline tele-: ギリシャ語 tēle「遠く」）
# メモ: revise はアプリの意味が「改訂する，見直して書き直す」なので、テロップに合わせて「見直す」で上書き
# メモ: provide はアプリのパーツが pro＋vis なので、つづりに合わせて vid を指定（Etymonline provide: pro "ahead" + videre "to see"）
# メモ: re・e・pro を root 場面にするとまとめの見出しから vis が落ちるので text 場面
