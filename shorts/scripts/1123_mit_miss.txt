# 型: ①カタカナ語 mit / miss（2026-11-23・Roots #38）
# タイトル: Roots #38 ①カタカナ語 mit / miss（11/23 投稿2）｜Rootsで英単語｜語源で一発暗記
# 語根: mit
# メモ: transmit・submit・dismiss・mission はアプリの見出し語（パーツと意味はアプリのデータ: trans(越えて)・sub(下で)＋mit(送る)、dis(離れて)＋mis(送る)）。missile はアプリの見出し語にないので kata でパーツを指定（ile はアプリの「できる」）。mission も kata ではつづりに合わせて miss を指定
# メモ: kata の miss(送る) はアプリの miss の絵（的を外す）と意味が違うので、絵は出ず文字になる（ℹ。問題ではない。kata 画面はもともと絵なし）。dismiss はアプリのパーツ（dis＋mis）のまま出すので、最後の s だけ黒になる（アプリと同じ表示）
# メモ: trans・sub・dis を root 場面にするとまとめの見出しから mit が落ちるので、1121_press と同じく text 場面
# メモ: 前後の日と重ねない: 11/22 magn/anim、11/24 bene/dict・in/ex と重ならない（ex-/e-/in- の語は使わない。emit・emission は使わない）
# メモ: 語源の根拠: Merriam-Webster mission（Latin missio「送り出すこと」← mittere to send）、Merriam-Webster missile（Latin missilis ← mittere to throw, send）、Merriam-Webster transmit（Latin transmittere ← trans- ＋ mittere to send）、Merriam-Webster submit（Latin submittere to lower, submit ← sub- ＋ mittere to send）、Merriam-Webster dismiss（Latin dimissus ← dimittere ← dis- ＋ mittere to send）、Etymonline message（Latin missus ← mittere "to release, let go; send, throw"。メッセージは今回は声に出さないが同じ仲間）
# メモ: 英検級は言わない（word 画面にはアプリの級が出る）。例文はオリジナル
