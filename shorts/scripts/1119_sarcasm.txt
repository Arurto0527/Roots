# 語根: sarc
# メモ: sarcasm・sarcastic・sarcophagus はアプリの見出し語にないのでパーツを指定。sarcastic・sarcophagus は仲間として見せる語なので「番号なし」
# メモ: 語源の根拠: Etymonline sarcasm（ギリシャ語 sarkasmos ← sarkazein「肉をはぎ取る」← sarx/sarkos「肉」）、Etymonline sarcophagus（sarx「肉」＋phagein「食べる」＝肉を食べる石）
# メモ: sarkazein「肉をはぎ取る」は MW では推測とされるのでテロップは「？」、ナレーションは「と言われます」
# メモ: 日本語の「皮肉」に肉が入っているのは偶然（語源のつながりはない）と言う
# メモ: 受験向けの語ではないので、まとめの欄は「今日の単語」。まとめは3.2秒
