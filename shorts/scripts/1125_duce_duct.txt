# 語根: duc
# メモ: produce・reduce・deduce はアプリの見出し語（パーツと意味はアプリのデータ: pro(前へ)・re(後ろへ)・de(下へ)＋duc(導く)）。duct は見出し語にないので kata でパーツを指定。conductor は conduct の related にある語（con(共に)＋duct(導く)＋or(人)）なので kata でパーツを指定
# メモ: pro・re を root 場面にするとまとめの見出しから duc が落ちるので、1121_press・1123_mit_miss と同じく text 場面。deduce の de はアプリでは「下へ」だが、Merriam-Webster では deducere＝lead away（導き離す）で「下へ」と言うとずれるので、de の意味は声に出さず「手がかりから答えを導き出す」（アプリの imagery の考え方）で説明する
# メモ: 前後の日と重ねない: 11/23 trans・sub・dis・mit、11/24 bene・dict・in/ex・hale、11/26 carn・vor・flat、11/25 投稿1の mort・gage は使わない。in- の induce・intro- の introduce・e(外へ) の education は 11/24 の in/ex と近いので使わない。dict・predict も使わない
# メモ: 語源の根拠: Merriam-Webster duct（New Latin ductus ← Latin「導くこと」← ducere to lead。Medieval Latin では aqueduct）、Merriam-Webster conductor（Medieval Latin conductor「escort, guide」← condūcere、Medieval Latin では to lead, escort）、Merriam-Webster produce（Latin producere ← pro- forward ＋ ducere to lead）、Merriam-Webster reduce（Middle English「to lead back」← Latin reducere ← re- ＋ ducere to lead）、Merriam-Webster deduce（Latin deducere, literally, to lead away ← de- ＋ ducere to lead）
# メモ: 注意: コンダクターは日本語では「ツアーコンダクター（添乗員）」「指揮者」。どちらも「みんなを導く人」なので語源とずれない。英検級は言わない（word 画面にはアプリの級が出る）
# メモ: 開発係へ: まとめの見出しに duct も出すため {summary 見出し=duc・duct} にした
# メモ: 語源チェック係の提案を反映: deduce は「推定する（estimate と誤解されやすい）」→「推論する」
# メモ: 開発係（11/17）: deduce の画面の訳がアプリの「推定する」のままだったので、{word deduce =推論する} にして画面とまとめの訳を「推論する」にした（パーツはアプリのまま。アプリのデータは変えていない）
