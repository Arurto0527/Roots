# 語根: pend
# メモ: suspend はアプリの見出し語（パーツと意味はアプリのデータ: sub(下で)＋pend(ぶら下がる)）。pendant・pending は depend・suspend の related にある語なので kata でパーツを指定（ant はアプリの「もの」、ing はアプリの「～している」）。append・perpendicular はアプリの見出し語にないのでパーツを指定（ap はアプリの「～へ」、per はアプリの「すっかり」）
# メモ: sub・ap を root 場面にするとまとめの見出しから pend が落ちるので、1121_press・1125_duce_duct と同じく text 場面。perpendicular の per は声に出さず「おもりをぶら下げた糸」で説明する
# メモ: 前後の日と重ねない: 11/25 mort・gage・duc、11/26 carn・vor・in/de・flat（depend・independent は使わない。in- と同じ im- の impending も使わない）、11/28 ambi・dext・com・ple/pli（compensate は使わない）、同日の投稿1の quar は使わない
# メモ: 語源の根拠: Merriam-Webster pendant（Middle English pendaunt「ベルトの垂れた端」← Anglo-French pendant「hanging, dangling」）、Merriam-Webster pending（French pendant「during」← pendre「to hang」の現在分詞。法律で「まだ決まっていない訴訟」に使われた）、Merriam-Webster suspend（Latin suspendere ← sus-（sub-「up from below」）＋ pendere、pendere はもとは「to hang」の意味だったらしい）、Merriam-Webster append（Middle French apendre「to hang on, suspend」← Late Latin appendere ← ad- ＋ pendere）、Merriam-Webster perpendicular（Latin perpendiculum「plumb line（下げ振り）」から。Kids 版は per- thoroughly ＋ pendēre to hang）
# メモ: 語源の根拠: Etymonline の *(s)pen- の項（etymonline.com）で pendere「to hang, cause to hang; weigh; pay」と、pendant・pending・suspend・append・pendulum が同じ仲間として並ぶことを確認
# メモ: 注意: append は古典ラテン語では「量って払う」の意味（Merriam-Webster）。ぶら下げる意味はフランス語経由なので、ナレーションは「後ろにぶら下げて足す」までにして、ラテン語の意味は言い切らない。perpendicular の perpendere「慎重に量る」の説もあるので、声は「下げ振り（ぶら下げたおもり）から」とだけ言う。英検級は言わない（word 画面にはアプリの級が出る）
