# 語根: ple
# メモ: compliment・complete はアプリの見出し語（compliment id1005 com(すっかり)+ple(満たす)＝褒め言葉／complete com(すっかり)+ple(満たす)＝完全な）。complete はパーツ指定なし。compliment はつづりどおり pli を見せるため com(すっかり)+pli(満たす)+ment(名詞) を指定（後の pair もこれを使う）。complement はアプリでは complete の related にだけある語なのでパーツを指定（com(すっかり)+ple(満たす)+ment(名詞)＝補うもの）。後の pair はそれを使う
# メモ: 語源の根拠: Etymonline complement（14世紀後半「完成させる手段」、古フランス語 compliement ← ラテン語 complementum ← complere「満たす」＝ com-（強め）＋ plere「満たす」）。Merriam-Webster complement（Latin complēmentum ← complēre to fill up, complete ＋ -mentum）。Etymonline compliment（1570年代「礼儀・敬意の行い」、もとのつづりは complement。1650年ごろフランス語を通して compliment に。イタリア語 complimento ← complire ← ラテン語 complere。「礼儀の務めを満たすもの」という考え方。「褒め言葉」の意味は19世紀初めから）。Merriam-Webster compliment（イタリア語 complimento はスペイン語 cumplimiento「礼儀として申し出ること」から。cumplir「果たす・満たす」＋-miento）
# メモ: 発音: Merriam-Webster で complement（名詞）・compliment（名詞）とも ˈkäm-plə-mənt で同じ（アプリの compliment は /ˈkɑːmplɪmənt/）
# メモ: 注意: 「e は complete の e」「i は I（私）をほめて」は語源ではなく覚え方。ナレーションでも「覚え方」と言う。compliment の経路は辞書で「スペイン語→イタリア語→フランス語→英語」（MW）なので「スペイン語などを通って来た」とだけ言い、細かい順番は言わない
