# 語根: quarant
# メモ: quarantine はアプリの見出し語にないのでパーツを指定（quarant＝40、ine はアプリの「名詞」）。quarter はアプリの見出し語（パーツと意味はアプリのデータ: quart(4番目)＋er(もの)）。quartet は quarter の related にある語なので パーツを指定して「番号なし」
# メモ: 語源の根拠: Merriam-Webster quarantine（partly French quarantaine ← quarante forty ← Latin quadraginta ← quadra-（akin to quattuor four）＋-ginta、partly Italian quarantena「quarantine of a ship」← quaranta forty。sense 1 は「a period of 40 days」）
# メモ: 語源の根拠: Etymonline quarantine は本サイト（etymonline.com）の各言語版が取得エラーで読めず、日本語版（etymonline.com/jp）で確認：1660年代「疫病の疑いのある船を隔離する期間」、Italian quaranta giorni「40日間」← Latin quadraginta。ヴェネツィアの政策で、ペストの国から来た船を港の外で40日待たせ、潜伏した病気がないか確かめた。1520年代の英語では「未亡人が夫の家に残れる40日」の意味もあった
# メモ: 語源の根拠（仲間）: Merriam-Webster quarter（Latin quartarius ← quartus fourth）、Merriam-Webster quartet（Italian quartetto ← quarto fourth ← Latin quartus）。quadraginta の quadra- は quattuor「4」の仲間（Merriam-Webster quarantine）
# メモ: 注意: 「なぜ40日なのか」（聖書の40日など）は Etymonline・Merriam-Webster とも理由を書いていないので「諸説あります」とだけ言う。ラグーサ（ドゥブロヴニク）の30日、1377年という年は辞書どうしで書き方が一致しないので声に出さない。ヴェネツィアの話は Etymonline の説明として「〜と説明されています」にする。英検級は言わない（word 画面にはアプリの級が出る）
