英単語アプリ「Roots」の入れ方

語源で覚える英単語アプリです。無料で、ホーム画面に置けばアプリのように使えます。

① スマホのカメラで QR コードを読みとる
https://arurto0527.github.io/Roots/
LINE などのアプリの中で開いたときは、iPhone は「Safari で開く」、Android は「Chrome で開く」を選んでください。

iPhone（Safari）

  1. Safari で開く
  2. 画面下の 共有（□に↑のマーク）をタップ
  3. 下へスクロールして ホーム画面に追加 をタップ
  4. 右上の 追加 をタップ

共有ボタンが見えないときは、画面を少し下へスクロールすると出てきます。

Android（Chrome）

  1. Chrome で開く
  2. 右上の ︙（点が3つ）をタップ
  3. ホーム画面に追加 か アプリをインストール をタップ
  4. インストール（または 追加）をタップ

画面の下に「インストール」の案内が自動で出たときは、それをタップしてもOKです。

知っておいてほしいこと

  • 次からは、ホーム画面の Roots のアイコン から開いてください。
  • 学習の記録は そのスマホの中 に保存されます。別のスマホや別のブラウザで開くと、記録は最初からになります。iPhone は、Safari で開いたときとアイコンから開いたときでも記録が別々です。いつもアイコンから開きましょう。
  • 入れたら、ネットにつないだ状態でアイコンから一度開いてください。そのあとは、ネットがなくても使えます（まだ聞いていない発音は、ネットにつながっているときだけ鳴ります）。
